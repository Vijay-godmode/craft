# ATS Checklist

- Use semantic headings: "Summary", "Experience", "Education", "Skills".
- Avoid images, graphics, and complex tables.
- Use standard fonts (Arial, Calibri, Times New Roman).
- Prefer DOCX or simple PDF without unusual encodings.
- Include contact info in plain text at top of document.
- Add a dedicated `Skills` section with comma-separated or bullet list.
- Avoid headers/footers for critical data (some ATS ignore them).
- Use standard date formats and consistent job titles.
- Keep formatting simple: bullets, bold for headings only.
- Test generated resumes with open-source parsers to validate extraction.
